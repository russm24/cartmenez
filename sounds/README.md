# Sound bytes

Drop `.wav`, `.mp3` or `.ogg` files here. The file name (without extension) is
the name Claude sees, so name them descriptively: `evil_laugh.wav`,
`airhorn.mp3`, `sad_trombone.ogg`.

Optionally add `sounds.json` (see `sounds.example.json`) to give Claude a short
description of each clip so it picks the right one.

Pre-recorded voice messages work the same way: e.g. `welcome_message.mp3`.

Only use audio you have the rights to — this folder is git-ignored so clips
never get committed.
